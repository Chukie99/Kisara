# Alur desktop yang disederhanakan

Home dimulai dari pilihan YouTube/transkrip atau ide sendiri. Draft manual dan arahan tetap disimpan dalam state saat berpindah pilihan. Kolom sinopsis baru muncul pada mode manual atau setelah intake menghasilkan ide. Sumber yang telah berhasil diolah diringkas; Ganti bahan sumber membuka input kembali. Error intake tetap tampil dan link gagal tetap ada. Tombol lanjut tidak aktif untuk draft kosong.

Arahan tambahan berisi audiens, sudut dan kontribusi kreator; tertutup pada awalnya dan nilai tetap ikut dikirim. Pilihan faktual/fiksi tetap terlihat. Mode dan catatan sumber yang perlu diperiksa tidak disembunyikan dari hasil. Pengaturan awal format/gaya/bahasa/suara bisa dibuka sesuai kebutuhan.

Langkah proyek tetap empat, dengan label Ide & durasi, Naskah & prompt, Visual & suara, Edit & ekspor. Tidak ada migrasi atau perubahan nomor langkah/database. Ide memprioritaskan ringkasan dan durasi; impor ulang sumber, bahasa/suara/model, dan galeri gaya memakai bagian yang bisa dibuka. Grid menjadi satu kolom pada lebar minimum agar form tidak terjepit.

Naskah membuka Narasi lengkap secara default, dengan waktu/nomor terpisah dari ucapan, salin dan ekspor TXT/DOCX. Dialog yang sudah tersimpan di teks narasi tetap ikut. Tag suara dibersihkan melalui shared/speech yang sama. Edit per adegan dan Prompt Google Flow tersedia melalui tab; pembuatan visual mengarahkan tab ke Flow agar progres/kegagalan terlihat. Pengaturan tempo/pembawaan tetap bisa dibuka di halaman yang sama. Export narasi menggunakan IPC yang sudah ada dengan kind narration, tanpa memerlukan prompt visual siap.

Visual & suara menampilkan narasi dan prompt Flow sebagai aksi utama, panduan impor pada klip, dan Alat lainnya untuk generasi massal, JSON Colab, gambar ulang dan video AI. Alat lama tetap tersedia; tidak mengubah antrean atau perhitungan biaya. Editor, timeline, FFmpeg dan aturan preview/ekspor tidak berubah.

Verifikasi dilakukan dengan typecheck/build dan dev harness pada profil sementara, ukuran 1180×720. Uji mencakup sumber lebih dulu, hasil review, penyimpanan arahan/durasi, akses pengaturan tertutup, narasi lengkap, edit per adegan, Flow dan alat generasi. Clipboard, TXT dan DOCX diperiksa memuat seluruh empat adegan demo. Tidak mengubah proyek/kunci asli atau memakai layanan AI sungguhan untuk uji ini.
