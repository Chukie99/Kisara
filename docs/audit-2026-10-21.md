## Pemeriksaan yang lolos

- `npm run typecheck` dan `npm run build`.
- Layanan LLM: JSON melalui prompt pada endpoint custom, pembacaan error AtlasCloud bertingkat,
  penyembunyian ID/kunci dari pesan, pembatasan retry, fallback format yang didukung.
- Naskah panjang: pengembangan kerangka ke 86 adegan, perbaikan ID yang hilang, pelestarian draft pada
  jawaban tidak lengkap, dialog yang benar-benar masuk ke narasi.
- Visual: urutan global, jawaban terbalik, perbaikan kelompok kurang, penurunan 6 → 3 → 1 saat timeout,
  resume dari adegan yang gagal, invalidasi setelah edit, pembatalan tanpa retry.
- Google Flow: timestamp bersama, pemisahan label dari prompt, identitas dan gaya, pemblokiran prompt basi,
  ekspor TXT serta DOCX melalui IPC. Simulasi UI memakai 86 adegan dan diperiksa lewat log serta screenshot.
- Gambar: normalisasi WebP melalui IPC, penolakan gambar hitam/kosong dan blokir ekspornya; alias pemeran.
- Hugging Face (HTTP tiruan): hanya mengambil event selesai, URL relatif, batas origin untuk token,
  penolakan URL asing, antrean serial gambar/potret dan pembatalan job.
- Audio: dialog SAPI demo, efek bawaan terpasang/terdengar di pratinjau, penautan ke klip, pemasangan ulang
  tanpa duplikasi, penghapusan efek melalui timeline; aturan durasi dan konversi teks TTS.
- Ekspor MP4 demo selesai: `tmp/bugcheck/quality-export/demo-export-7.mp4`, durasi sekitar 17,47 detik,
  H.264 1920×1080 30 fps, AAC 48 kHz stereo. Seluruh video/audio didekode FFmpeg tanpa error, frame dan
  caption diperiksa secara visual.

## Batas audit

- Pengujian 86 adegan memakai jawaban AI tiruan; bukan bukti keberhasilan 86 permintaan pada provider asli.
- TTS demo memakai Windows SAPI. Kualitas emosi Gemini, ElevenLabs atau Supertonic memerlukan dengar hasil
  produksi sebenarnya. Kualitas ilustrasi, koherensi hasil model, serta daya tarik cerita juga perlu review.
- HTTP 400 generik AtlasCloud tidak mengungkap penyebab rinci. Perbaikan kompatibilitas tidak menjamin
  provider menerima model, kuota atau payload tertentu. Tidak ada uji ulang provider asli pada audit ini.
- Installer baru tidak dibuat. Hasil build aplikasi tersedia di `out/`.
- Masalah pratinjau video yang bergetar pada perangkat tertentu dan fitur undo/redo tetap tercatat di
  [masalah-diketahui.md](masalah-diketahui.md).

## Memakai build baru

Tutup Kisara sepenuhnya, lalu jalankan `START - WIN.bat`. Naskah tersimpan tetap tersedia. Checkpoint disk
berlaku untuk prompt yang diproses mulai build ini; prompt parsial versi lama yang hanya ada di memori
tidak dapat dipulihkan setelah proses lama ditutup. Setelah itu, tombol **Susun/perbarui prompt** melanjutkan
checkpoint yang cocok tanpa mengulang kelompok lengkap.

## Audit lanjutan: Ambil ide dari YouTube

Keluhan: proses berhenti tanpa pesan yang jelas. Tanpa link sumber atau error asli, penyebab kasus pengguna
belum dapat dipastikan. Audit menemukan error yt-dlp ditelan, lalu diarahkan ke unduhan audio hingga 15
menit; toast sementara juga membuat kegagalan terlihat seperti berhenti tanpa alasan.

Perbaikan: error caption dipertahankan, hanya rate limit 429 dicoba sekali lagi, fallback audio memeriksa
kesiapan Whisper, timeout subprocess mengenali proses yang dibunuh Node, unduhan alat dibatasi dua menit.
Link video dinormalisasi dan config yt-dlp global diabaikan. Runtime Node Electron diaktifkan untuk versi
yt-dlp yang mendukungnya; versi lama tidak menerima flag baru. Caption 80–400 karakter kini diterima dan
nomor cue/timestamp VTT tidak masuk transkrip. Hasil Whisper pendek tidak lagi ditandai selalu parsial.

Home dan langkah Ide menampilkan status serta error menetap dan menjaga input untuk retry. Permintaan
podcast tidak menimpa sinopsis, judul atau bahasa yang diedit selama menunggu.

Uji `tmp/bugcheck/youtube-audit-checks.cjs` memakai proses/Whisper tiruan dan file sementara: variasi link,
penolakan domain palsu, parsing VTT, caption pendek, penolakan caption tanpa unduhan audio, Whisper belum
siap, error audio 403, flag parsial, timeout proses dan pembersihan file semuanya lolos. Electron yang
terpasang berhasil berjalan dalam mode Node (`v24.21.0`). Regresi LLM, autosave, checkpoint, produksi,
naskah 86 adegan, visual adaptif, Hugging Face, Freesound, serta Flow/narasi/nama aset TXT/DOCX diuji ulang
dan lolos. Layanan AI dan akses YouTube asli belum diverifikasi pada kasus pengguna ini.

Harness UI `youtube-ui-v3.log` lolos untuk loading, error menetap, pelestarian link, dan retry berhasil di
Home maupun langkah Ide; screenshot keduanya diperiksa. Audit produksi ulang memakai
`audit-youtube-full-userdata`: dialog, impor WebP, efek lokal terdengar/tertaut/tanpa duplikasi dan hapus
efek lewat timeline lolos. Polling ekspor harness 55 detik terlalu pendek pada mesin saat audit; pemeriksaan
SQLite setelahnya membuktikan job ekspor `done`, progress 1, tanpa error. Hasil
`tmp/bugcheck/quality-export/demo-export-8.mp4` berdurasi 17,47 detik, H.264 1080p/30fps dan AAC stereo.
FFmpeg mendekode seluruh hasil tanpa error; frame beserta caption diperiksa. Job penolakan gambar hitam
yang `failed` dalam profil ini adalah kasus uji yang disengaja, bukan ekspor demo yang gagal.
