# Pemulihan prompt dari gangguan server AI

Screenshot pengguna menunjukkan naskah 43 adegan tersimpan, sementara penyusunan visual 0/43 gagal
dengan HTTP 502 dari endpoint custom, model `combo:recommended-free`. Screenshot tidak mengungkap
penyebab di router/provider dan tidak membuktikan saldo habis.

Sebelumnya hanya timeout yang mendapat fallback kelompok kecil. HTTP 502 langsung menghentikan proses.
Kini HTTP 500/502/503 boleh dicoba ulang dua kali untuk seluruh satu proses visual, dengan jeda 2 dan
5 detik. Status jeda dan pengiriman ulang ditampilkan. Abort menghentikan jeda; tidak ada pergantian
model/provider secara diam-diam. Hasil tervalidasi tetap di checkpoint disk dan tidak diminta ulang.

`tmp/bugcheck/visual-server-checks.cjs` menguji 43 adegan dengan dua gangguan 502 sementara, kegagalan
menetap yang berhenti setelah dua retry, checkpoint enam adegan dan resume tepat adegan tujuh, serta
pembatalan saat backoff. HTTP 400/401/403/429 tidak memicu retry ini. Regresi kerangka 86 adegan,
fallback timeout 6 → 3 → 1, penomoran, cache setelah restart, serta validasi TXT/DOCX tetap lolos.
`compat-400-checks.cjs` memastikan aturan fallback JSON dan perlindungan informasi rahasia tetap lolos.
Typecheck dan build berhasil. Pengujian memakai respons AI tiruan, bukan akun atau cerita pengguna.

Harness aplikasi `server502-ui.log` juga lolos untuk progres, error menetap, status setelah halaman dimuat
ulang, pembatalan, dan 86 prompt selesai dengan tombol ekspor aktif. Screenshot hasil diperiksa.

Retry terbatas hanya membantu gangguan sementara. Gangguan endpoint/provider yang menetap tetap
memerlukan pemulihan server atau pilihan model lain dari pengguna.
